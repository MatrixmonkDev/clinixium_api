# Email Templates - Shared Resources

## Logo Instructions

Place your logo file here as `logo.png` (PNG format recommended).

**Specifications:**
- Format: PNG
- Recommended size: 180x60 pixels
- Background: Transparent (recommended)
- Max file size: 500KB

**How to add your logo:**
1. Copy your logo PNG file to this folder
2. Rename it to `logo.png`
3. Restart the server to load the new logo

**Current status:** No logo file found. The email header will use a text fallback if the logo is missing.
